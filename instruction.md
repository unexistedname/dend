Saya ingin kamu membuat sebuah website untuk membuat karakter dnd 5e

# Requirement
- Gunakan rulebook dnd 5e 2014
- Fitur menambah karakter (nama, etc)
- Pemilihan class, skill, etc (lengkap)
- Berikan penjelasan untuk spells dan items (seperti apa fungsi, cara penggunaa(?), durasi, range)
- Karakter yang sudah jadi dapat diekspor/download dalam bentuk markdown (formatnya bebas, sesukamu), dan png character sheet dnd (opsional, katakan kalau kamu tidak mampu membuat gambarnya)

# Mekanik
- Berikan penjelasan singkat tentang elemen tersebut saat dihover (kalau tidak ada penjelasan, maka tidak usah dipaksakan)
- Hadirkan fitur auto-constraint (misal: apabila kita memilih ras dragonborne, maka kita tidak bisa menggunakan beberapa item atau spell).

# Constraint
- Dilarang membuat penjelasan tambahan di luar rulebook
- Dilarang membuat elemen tambahan di luar rulebook
- Dilarang mengatur stat yang tidak sesuai dengan rulebook

# Tambahan
Saya tidak sepenuhnya mengerti tentang dnd, silahkan bantah argumen saya apabila kamu menemukan informasi tambahan.
